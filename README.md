## 🚀 Deployment

This site is designed to run on **GitHub Pages** with a custom domain:

1. Push the repository to GitHub.
2. In **Settings → Pages**, set the source to `main` branch root (`/`).
3. The `CNAME` file keeps `crackthehack.in` pointed at GitHub Pages.
4. Point your DNS (`A`/`AAAA` or apex `CNAME`) at the GitHub Pages host.

> [!NOTE]
> Sub-pages must be deployed at the **root** of the Pages site so relative links
> like `android/index.html` resolve correctly.
